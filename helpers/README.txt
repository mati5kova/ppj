Geslo za uporabnika student je student.
Razporeditev tipkovnice lahko spremenite s klikom na si ali us v spodnjem desnem kotu zaslona.

Nameščena programska oprema:

    - Prolog — dostopen prek swipl ali prolog.
    - Ocaml — uporabite utop.
    - Haskell interpreter, dostopen prek ghci.
    - Lambda interpreter (glej https://plzoo.andrej.com/language/lambda.html — dostopen prek lambda).
    - LibreWolf (beri Firefox: https://librewolf.net/).
    - Neovim — dostopen prek nvim (https://neovim.io/).
    - Kate, tekstovni urejevalnik (https://kate-editor.org/sl/).
    - Okular, PDF bralnik (https://okular.kde.org/sl/).
    - Konsole, terminal (https://apps.kde.org/sl/konsole/).

Primeri izvornih datotek so v domačem imeniku: ~/test.\*.

## OCaml - utop

```bash
utop

(+);;
( * );;
```

## Prolog - swipl

```bash
swipl datoteka.pl

ali

swipl
?- [datoteka].

help(ime_ukaza).
```

## Haskell - ghci

```bash
ghci (-Wall)

:load datoteka.hs

:info funkcija ali operator ali ...
```
